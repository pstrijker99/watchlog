WATCHLOG — install on your phone

1. Get a free TMDB key: themoviedb.org > Settings > API > Request an API key (Developer).
2. Put this folder online (one time). Easiest:
   - Netlify: sign in at app.netlify.com, open "Deploy manually" (Netlify Drop) and drag this folder in.
   - or GitHub Pages: new repository, upload these files, Settings > Pages > deploy from main branch.
3. Open the link in Chrome on your phone > menu (three dots) > "Add to home screen" > Install.
4. Open Watchlog > ••• > paste your TMDB key > Check key.
5. Optional, for IMDb ratings: get a free key at omdbapi.com > API Key, paste it under "OMDb key".

Your log is stored on the phone. To keep it safe when you switch phones, set up
Cloud backup in ••• with a GitHub token (only the "gist" box ticked, no expiration).
On a new phone: install the app, paste the same token, tap Restore.
