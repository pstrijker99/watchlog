WATCHLOG — install on your phone

1. Put this folder online (one time). Use Netlify: sign in at app.netlify.com,
   open "Deploy manually" (Netlify Drop) and drag this folder in.
   Avoid a public GitHub repository: the app contains built-in API keys.
2. Open the link in Chrome on your phone > menu (three dots) > "Add to home screen" > Install.
3. That's it: TMDB and OMDb keys are built in. You can paste your own in ••• if you prefer.

Your log is stored on the phone. To keep it safe when you switch phones, set up
Cloud backup in ••• with a GitHub token (only the "gist" box ticked, no expiration).
On a new phone: install the app, paste the same token, tap Restore.
Friends using the same link each get their own separate log on their own phone.
